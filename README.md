# Rabiola 🪁

Jogo 3D de soltar pipa no campinho de várzea, feito com **Three.js** e **Ammo.js**, direto no navegador.
Modo livre, desafios, disputa contra bots e **disputa online** (cruze a linha, enrosque a rabiola, apare as avoadas).

## Como jogar

1. Instale o [Node.js](https://nodejs.org) (versão 18 ou mais nova).
2. Rode `iniciar-servidor.bat` (Windows) ou `npm start`.
3. Abra `http://localhost:8080` no navegador.

Controles, modo online, versão para portais, celular e estrutura do código: veja o **[LEIA-ME.md](LEIA-ME.md)**.
Modelos 3D (.glb) e texturas do jogo: pasta **[Assets](Assets/LEIA-ME.md)**.
